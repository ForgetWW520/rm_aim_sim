# 使用、命令行与配置参考

先完成 [README](../README.md) 的引擎安装和资源导入。所有命令从仓库根目录执行；`run.sh` 本身也可从其他目录调用，会自动定位工程。

## 命令行

Godot 参数放在 `--` 前，项目参数放在 `--` 后。例如：

```bash
./run.sh --max-fps 60 -- --remote --config=res://configs/combined.cfg
./run.sh --headless -- --remote --quit-after-seconds=10
```

| 项目参数 | 作用 |
|---|---|
| `--config=路径` | 加载场景配置，默认 `res://configs/default.cfg`；支持绝对路径或 Godot 的 `res://` / `user://` 路径 |
| `--remote` | 启动后立即启用本机自瞄控制；没有它仍可在图形界面打开开关 |
| `--no-ipc` | 不建立共享内存通道，不提供外部控制、状态或相机帧 |
| `--no-network` | `--no-ipc` 的历史别名；当前没有网络传输 |
| `--capture=路径` | 图形模式启动约 1 秒后保存窗口截图，不是纯传感器 raw 图像；路径需可写 |
| `--quit-after-seconds=秒` | 按墙钟自动退出，正数才生效，退出时打印 `FINAL_STATS` |

`--headless` 是 Godot 参数，只运行仿真/状态/理想角点，不渲染像素。无桌面机器若需真实图像，须自行配置可用的图形会话与 OpenGL 环境，不能把 `--headless` 当作离屏相机模式。项目本身没有 `--ideal`、`--no-fire` 或 `--webviz` 选项；那是部分外部视觉程序的参数。

## 操作与保存

| 操作 | 效果 |
|---|---|
| 方向键 | 手动调整云台；输入框有焦点时用于编辑 |
| 按住 F / 按住跟踪 | 内置真值辅助连续跟踪，不自动开火 |
| 按住 Space / 按住发射 | 持续发射 |
| P | 暂停/继续；物理时间冻结，IPC 和界面仍轮询 |
| R | 重置本轮：恢复血量、时间、计数、云台及运动初态，创建新会话 |
| V | 切换第一/第三人称；第三人称可右键拖动、滚轮缩放 |
| 保存配置 | 写 `user://last_scenario.cfg`，界面显示绝对路径；下次须用 `--config=` 显式加载 |
| 导出结果 / 保存相机 | 默认写被 Git 忽略的 `captures/`；与实时 raw 协议不是同一接口 |

窗口失去焦点会停止本地按键射击。启用外部控制后本地跟踪/发射不覆盖远端命令。参数修改即时生效，通常不重置时间、计数、在飞弹丸和会话；暂停/恢复、重置及外部控制切换则改变会话。

第一人称主画面是未做曝光处理的渲染，可能因填满窗口而裁边。右上角预览与共享内存帧使用完整的、曝光处理后的相机图像。调曝光时应看右上预览，不能看主画面。

## 配置格式与预设

配置使用 Godot ConfigFile，不是 TOML/YAML。向量写 `Vector3(x, y, z)`，布尔写 `true/false`，字符串加引号。缺省项来自 `scripts/settings.gd`，不是从 `configs/default.cfg` 二次合并。未知 section/key、错误类型和越界组合会报错并退出。

| 文件 | 场景 |
|---|---|
| `configs/default.cfg` | 完整默认配置，4 m 静止蓝方步兵 3 |
| `configs/translate.cfg` | 开启 1.5 m/s 平移，往返半程 1.5 m |
| `configs/spin.cfg` | 仅自转，其他参数继承代码默认值 |
| `configs/combined.cfg` | 平移加自转 |
| `configs/vision.cfg` | 显式固定默认 1440×1080 / 45° 相机，其他参数继承默认值 |

配置与协议统一为 m、s、rad、rad/s、rad/s²；**例外：`camera.vertical_fov` 为度，`brightness_gain` 为倍率**。界面部分角度和发射延迟显示为度/ms，保存时仍转换回配置单位。

## 所有配置项

下表范围来自当前 `Settings.validate()`，同时还须满足后文的组合约束；GUI 范围可能更窄。数值应为有限数，不接受 NaN/Infinity。标记“整数”的字段不能有小数。

### appearance：外观

| 字段 | 默认值 | 范围 / 含义 |
|---|---|---|
| `robot` | `"infantry_3"` | `infantry_3/infantry_4/infantry_5/hero/sentry` |
| `team` | `"blue"` | `blue/red`；协议给出字符串，算法颜色枚举自行映射 |
| `armor_model` | `""` | 空为内置外观；支持的模型与轴约定见 [models.md](models.md) |
| `armor_scale` | `1.0` | [0.001,1000]，自定义模型归一化后的倍率，不改变命中区 |
| `body_model` / `body_scale` | `""` / `1.0` | 历史兼容字段，当前不渲染车体；scale 校验 [0.001,1000] |

### target：目标与装甲

| 字段 | 默认值（步兵 3） | 范围 / 含义 |
|---|---|---|
| `center` | `Vector3(4,0,0.2603703641430668)` | 基准组装甲中心高度及平移轨迹中心，不是车体离地高度 |
| `translate` | `false` | 平移开关 |
| `speed` | `1.0` | [0,10] m/s，最高平移速度 |
| `acceleration` | `3.0` | [0.1,50] m/s²，启动/制动加速度 |
| `heading` | `π/2` | 世界系平移方向，绝对值 ≤20π；配置需写实际数字 |
| `travel` | `1.5` | [0.1,10] m，轨迹中心到端点的半程，总行程为两倍 |
| `rotate` | `false` | 绕世界 z 轴自转 |
| `omega` | `4.0` | [-25,25] rad/s，自转角速度 |
| `phase` | `π` | 初始旋转角，绝对值 ≤20π；配置需写实际数字 |
| `radius` | 由默认 0.550 m 旋转外廓换算 | [0.001,0.3] m，中心到装甲中心的水平半径，**不是界面的外廓直径** |
| `height_difference` | `-0.1` | [-0.1,0.1] m，奇数装甲相对偶数组的高度差 |
| `max_health` | `-1` | [-1,10000] 整数；-1 用车型预设，0 为初始战亡 |
| `module_width` / `module_height` | `0.140 / 0.125` | 各 [0.05,0.3] / [0.04,0.3] m，外形尺寸 |
| `armor_width` / `armor_height` | `0.135 / 0.125` | 各 [0.05,0.3] / [0.04,0.3] m，矩形命中区近似 |
| `armor_tilt` | `π/12` | [-π/4,π/4] rad，板面倾角 |
| `lightbar_spacing` | `0.135` | [0.05,0.3] m，灯条中心间距，用于 PnP 点几何 |
| `lightbar_length` | `0.056` | [0.02,0.15] m，灯条端点距离 |

省略尺寸项时按车型预设选大小装甲；英雄对应模块 0.235×0.127 m、命中区 0.230×0.127 m、灯条间距 0.230 m。默认血量英雄/步兵 350、哨兵 400。默认 `center.z`、`radius` 随模块几何换算；修改尺寸时优先省略这两项，让默认下沿高度和外廓重新计算，或自行给出合法值。

平移启动从静止加速，接近端点时制动至零，再换向；短行程可达不到设定最高速。运行中改运动参数从当前合法位置重新启动，不把轨迹中心累积平移。战亡后停在死亡位置/角度，重置恢复配置运动。

### gimbal：我方固定云台

| 字段 | 默认值 | 范围 / 含义 |
|---|---|---|
| `origin` | `Vector3(0,0,0.65)` | RM 世界位置，z∈[0.3,3] m |
| `barrel_length` | `0.22` | [0,0.5] m，从云台原点沿枪口前向伸出 |
| `max_speed` | `6.0` | [0.1,20] rad/s，两轴限速 |
| `max_acceleration` | `50.0` | [0.1,500] rad/s²，两轴限加速度 |
| `response_hz` | `6.0` | [0.1,30] Hz，二阶伺服响应参数，不是控制线程频率 |
| `pitch_min` | `-0.5235987755982988` | [-π/2+0.01,0] rad |
| `pitch_max` | `0.3490658503988659` | [0,π/2-0.01] rad，且大于 pitch_min |

yaw 可绕回，pitch 向下为正；原点固定，不模拟底盘移动或 roll。

### weapon：弹道与发射

| 字段 | 默认值 | 范围 / 含义 |
|---|---|---|
| `speed` | `23.0` | [1,100] m/s，出膛速率 |
| `rate` | `10.0` | [0.1,50] Hz，持续许可时的触发频率 |
| `delay` | `0.015` | [0,1] s，触发到出膛延迟 |
| `gravity` | `9.7833` | [0,20] m/s²，沿世界 -z |
| `lifetime` | `3.0` | [0.1,10] s，弹丸最大寿命；超出空间范围也会提前结算 |
| `damage` | `20` | [0,10000] 整数，每发基础伤害 |

17 mm 发射器固定，显示球径 16.8 mm，但判定使用质点抛物线；切换英雄是切换靶车型，不是切成 42 mm 发射器。命中区、外观几何和球体显示不是同一概念。

### camera：针孔相机

| 字段 | 默认值 | 范围 / 含义 |
|---|---|---|
| `width` | `1440` | [160,3840] 整数像素 |
| `height` | `1080` | [120,2160] 整数像素 |
| `vertical_fov` | `45.0` | [10,120] 度 |
| `brightness_gain` | `0.4` | [0,4]，仅相机输出/预览曝光，0 全黑；不改变主画面场景光照 |
| `offset` | `Vector3(0.08,0,0.04)` | 云台系中的光心偏移，向量长度 ≤0.5 m，无额外安装角 |

内参由分辨率/FOV 计算，畸变为零，不从真实相机 YAML 自动导入。曝光为先线性增益再饱和的外观近似，非物理曝光标定。修改几何或相机设置时接入端必须重新校验标定。

### ipc：本机通道

| 字段 | 默认值 | 范围 / 含义 |
|---|---|---|
| `channel` | `"default"` | 1–80 位英文字母、数字、下划线或连字符 |
| `state_hz` | `60.0` | [1,240] Hz，状态发布目标频率，受主循环调度限制 |
| `timeout` | `0.25` | [0.05,2] s，接收端有效控制指令的墙钟看门狗 |

没有配置端口/IP 的字段。通道是共享内存路径的一部分，不能在同通道启动多个仿真/客户端。`timeout` 是仿真接收命令超时；自瞄还须独立设置状态、图像与目标超时。

### 组合约束

- 所有配置向量须有限；target.center 与 gimbal.origin 距世界原点均 ≤25 m。
- 模块下沿必须 >0 且 ≤0.4 m，两个高度组都须满足；外形高度和倾角共同决定下沿，不是直接限制 center.z。
- 装甲必须有几何间隙，不能互相穿插或遮挡相邻板正面；整个旋转外廓直径 ≤0.600 m。radius 单独处于数值范围内并不保证合法。
- 更大尺寸、改变倾角/高度差时可能触发组合约束；界面滑条会动态限幅，手写配置需要自行保证。

## 同时运行多组仿真

新建自己的 cfg（无需修改默认配置），例如：

```ini
[target]
translate=true
speed=1.5
travel=1.5

[ipc]
channel="team_a"
```

```bash
./run.sh -- --remote --config=/absolute/path/to/team_a.cfg
python3 tools/camera_demo.py --channel=team_a --no-display --frames=30
```

另一组改用 `team_b`；目录、锁和图像彼此隔离。不要靠删锁或让多个控制端使用相同 channel 来实现共享。

## 排障与测试边界

先读启动日志的 `Aim Lab ready`、`local_ipc` 和 remote 状态。使用错误配置或撞上同通道仿真时会报错退出；这不是客户端网络超时。资源丢失先执行首次导入命令，确认引擎选择顺序与实际 `--version`。

核心测试与接口集成测试使用独立检查/通道。完整 GUI 冒烟测试包含键盘焦点与窗口操作，对窗口环境有要求；相机专项 `--camera-only` 不依赖键盘焦点。任何一项通过都不应被写成“任意自瞄模型已通过”。命令见 README 与接入指南。
